# Founder Town style: warm and cosy (draft)

Status: draft. No avatar direction has been chosen.

This style is designed from its own rules. Do not measure, sample or trace another product's art to set any value here.

## Mood

A small-town workshop late in the afternoon: soft shapes, knitwear, warm light, nothing sharp or corporate.

## Unchanged technical format

32×32 tiles, 32×48 character canvas, feet anchor at (16, 46), layered parts and integer zoom, as defined in `SPRITE_FORMAT.md`.

## Rules

| Item      | Rule                                                                              |
| --------- | --------------------------------------------------------------------------------- |
| Shapes    | Built from rounded forms. Avoid long straight runs and hard corners on characters |
| Outline   | 1px, warm cocoa `#5b3a3a`, never black or blue-grey                               |
| Shading   | Two tones per material. The dark tone sits along the underside of each form       |
| Dark tone | Shifts toward red-brown, never toward grey                                        |
| Faces     | Dark features in plum-brown `#3f2a33`, with blush on every avatar                 |
| Floor bg  | Concepts are judged on cream `#f4e6cf`                                            |
